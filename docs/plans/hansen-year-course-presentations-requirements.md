# Hansen 全年计量经济学 Quarto 讲义需求

**Version:** 1.0  
**Status:** Draft  
**Date:** 2026-08-02

## Problem Frame

本项目需要把 Bruce E. Hansen 2021 年版《Econometrics》书稿组织为一门跨度一年的研究生计量经济学课程。学生只系统学过李子奈、陈强、伍德里奇等本科入门教材，能够使用 OLS、基础检验、简单面板和 IV，但尚未形成 Hansen 所要求的矩阵推导、概率极限、识别、矩条件及依赖数据渐近理论语言。因此，课程不能机械压缩或逐页复述书稿，而必须显式补上从本科直觉到研究生计量语言之间的思维台阶。

全年只有 40 次、每次 90 分钟，共 60 个课堂小时，却需要覆盖书稿 29 章、附录 A/B 以及实证训练。可行方案是对全书实行分层覆盖：所有章节进入课程地图；核心理论逐步推导；带星技术证明和次要专题放入中文 Quarto 补充讲义与课后阅读；用 32 次主课建立理论主线，并用 8 次工作坊完成推导复盘、模拟、数据设定和结果解释。

## Requirements

| ID | Requirement | Priority | Notes |
|----|-------------|----------|-------|
| R1 | 在 `presentation/` 建立可独立渲染的 Quarto 项目，包含课程主页、教学大纲、共享主题、统一记号、补充材料、40 次分课讲义和构建说明。 | Must Have | 不直接改写会被现有脚本覆盖的 `docs/chXX/*.qmd`。 |
| R2 | 课程严格按 40 次、每次 90 分钟组织，其中 32 次为主课、8 次为“推导复盘 + R 实证/模拟”工作坊。 | Must Have | 工作坊穿插在关键方法模块之后，不集中堆到期末。 |
| R3 | Hansen 第 1–29 章及附录 A/B 全部进入课程覆盖表；采用分层讲授，核心章节逐步推导，带星技术证明和次要专题进入补充讲义或延伸阅读。 | Must Have | 每个章节必须能追踪到具体课次或补充材料。 |
| R4 | 梯度必须缓起步：课程开端充分讲授矩阵代数、概率与条件期望、随机样本和渐近语言；后续首次使用 FWL、delta method、MDS/FCLT、GMM、单位根、动态面板等工具时继续按需回补。 | Must Have | 不假设学生已熟练掌握附录内容。 |
| R5 | 每份主课 QMD 使用中文并固定包含：学习目标、先修检查、本科语言到 Hansen 语言的桥接、路线图、逐步推导、维数/条件核对、例子或应用、常见错误、课堂检查题、阅读页码、习题解答链接和中文教师备注。 | Must Have | 英文术语可在首次出现时括注，之后以中文叙述为主。 |
| R6 | 8 份工作坊 QMD 必须写清数据/样本、变量变换、模型设定、标准误或聚类层级、检验临界值、代码执行方式与结果解释；代码以 R 为主，路径相对项目根目录，缺少被忽略的本地数据时仍能渲染。 | Must Have | 默认可采用 `execute: false` 或提交轻量衍生结果，避免硬依赖 `hansen/`。 |
| R7 | 补充内容与辅助材料也必须是中文 Quarto 文档，至少覆盖矩阵代数、概率与条件期望、渐近工具、统一记号、R/数据复现指南、阅读与练习导航。 | Must Have | 辅助文档不是普通 Markdown 占位页。 |
| R8 | 项目必须具备可维护和可验证的构建边界：共享 RevealJS 配置与 SCSS、明确渲染目标、忽略构建产物、README 课程入口、源文件静态检查；在可获得 Quarto CLI 时完成全项目渲染检查。 | Must Have | 当前基础环境缺少 Quarto CLI，需提供可复现安装/检查路径。 |

## Success Criteria

1. `presentation/` 中恰有 40 份按课次编号的课堂 QMD，其中课程表明确标注 32 份主课和 8 份工作坊；每份均对应 90 分钟教学设计。
2. 课程覆盖矩阵逐一列出 Ch.1–Ch.29、Appendix A 和 Appendix B，且每项至少指向一份课堂讲义或补充讲义，不存在未映射章节。
3. 前 6 次课以数学、概率、CEF/投影与最小二乘代数为主，后续每个高级工具首次出现时均有先修回顾或补充材料链接。
4. 所有课堂与辅助 QMD 的教学叙述为中文；非显然记号首次出现时有定义，关键矩阵推导点明维数，引用 Hansen 时给出章节或书内/PDF 页码。
5. 每份主课至少包含一个完整的逐步推导、一个本科—Hansen 桥接、一个常见错误辨析和一组课堂检查题；工作坊满足 R6 的全部实证说明要求。
6. 项目在没有 `hansen/` 数据目录时仍可完成非执行式渲染；本地数据仅作为可选复现来源，不成为生成 HTML 的硬依赖。
7. 共享配置、主题、导航和构建说明无重复漂移；静态检查能发现缺课次、缺教师备注、缺阅读页码、错误内部链接及明显的幻灯片内容溢出风险。
8. README 提供课程入口、40 次结构、渲染命令和数据说明；构建产物不会污染 Git 工作树。

## Scope Boundaries

**In scope:**

- Hansen 2021 书稿第 1–29 章、附录 A/B 的全年中文教学组织。
- 40 次、每次 90 分钟的 RevealJS 分课讲义。
- 32 次主课和 8 次 R 实证/模拟工作坊。
- 中文教师备注、数学/概率补充讲义、统一记号、课程表和复现指南。
- 对现有 `docs/chXX/` 习题解答与 `scripts/r_companions/` 的链接和选择性复用。
- Quarto 配置、主题、构建与静态质量检查。

**Out of scope:**

- 对 Hansen 书稿逐页、等深度复述。
- 在课堂中完整讲授所有带星技术证明；这些内容进入补充讲义或阅读导航。
- 重写现有逐章习题解答、notebook 或 R companion。
- 提交受版权或 `.gitignore` 约束的完整书稿、教材数据和官方程序。
- 把讲者备注当作保密考试答案存储区。
- 本轮创建 LMS、自动评分平台或视频课程。

## Key Decisions

| Decision | Chosen | Rationale | Alternatives Considered |
|----------|--------|-----------|------------------------|
| 课程规模 | 40 × 90 分钟 | 用户明确指定；总计 60 小时，适合跨两学期实施。 | 32 周机械按章安排。 |
| 课堂构成 | 32 次主课 + 8 次工作坊 | 保证理论推导与实证判断同时训练。 | 全部 40 次均为理论课；将工作坊集中在期末。 |
| 覆盖原则 | 全章映射、分层讲授 | 在缓起步与全书覆盖之间建立可执行平衡。 | 逐页等深度覆盖；只选讲少数章节。 |
| 基础铺垫 | 前 6 次集中铺垫，后续按需回补 | Hansen 前言默认的数学统计基础高于目标学生现状。 | 把附录完全留给学生自学；连续两次孤立讲完附录。 |
| 文档语言 | 全部中文，术语首次出现可括注英文 | 与目标读者一致，同时保留检索原书术语的能力。 | 中英混写；正文英文、仅备注中文。 |
| 技术形态 | 独立 Quarto default project + RevealJS | 支持共享配置、分课渲染、讲者视图和课后滚动阅读。 | 一个巨型 QMD；把现有习题 QMD 直接切换为 RevealJS。 |
| 代码语言 | R 为主、默认无数据也能渲染 | 仓库已有 R companion 和 Hansen 数据路径约定。 | 全部改写为 Python；渲染时强制执行所有实证。 |
