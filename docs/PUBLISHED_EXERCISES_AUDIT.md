$$
\text{PDF 页}=\text{印刷页}+35.

这里的“题目一致”指估计对象、条件、分问和数据任务一致；纯粹的断行、拼写、标点及排版变化不计为实质差异。

## 出版版的实质变化

### Chapter 4：交叉引用随正文修订而变化

题目本身仍是 4.1–4.26，但下列引用必须按出版版改写：

| 习题 | manuscript | 出版版 |
|---:|---:|---:|
| 4.5 | (4.15)、(4.16) | (4.17)、(4.18) |
| 4.6 | Theorem 4.6 | Theorem 4.5 在线性估计量类中的证明 |
| 4.7 | (4.13)、(4.14)、(4.17)–(4.19) | (4.15)、(4.16)、(4.19)–(4.21) |
| 4.9 | (4.27) | (4.29) |
| 4.10 | (4.35) | (4.37) |
| 4.11 | (4.36) | (4.38) |
| 4.16 | (4.61) | (4.60) |
| 4.17 | (4.62)、(4.63) | (4.61)、(4.62) |
| 4.24 | §4.16 | §4.14 |
| 4.26 | §4.23、(4.55) | §4.21、(4.57) |

出版版把一般误差协方差写成 $\operatorname{var}(e\mid X)=\Sigma_1\sigma^2$，并将 Theorem 4.5 陈述为对所有无偏估计量的下界；Exercise 4.6 要求在线性估计量子类中证明它。解答必须明确：所给 $A=B+D$ 证明只覆盖题目要求的线性子类，不能冒充正文更强的全体无偏估计量定理。

### Chapter 12：删除一题并整体前移

出版版删除了 manuscript 的旧 Exercise 12.21（恰好识别时比较结构式与约简式中 $X_1$ 系数）。其余尾部题号整体前移：

| 出版版题号 | 对应 manuscript 题号 | 内容 |
|---:|---:|---|
| 12.21 | 12.22 | 已知条件方差时 GLS 写成 IV |
| 12.22 | 12.23 | AJR2001 实证 |
| 12.23 | 12.24 | AJR 2SLS bootstrap 标准误 |
| 12.24 | 12.25 | Card1995 实证 |
| 12.25 | 12.26 | Card IV 的 BC percentile 区间 |
| 12.26 | 12.27 | AK1991 黑人男性子样本 |
| 12.27 | 12.28 | 弱工具下渐近/bootstrap/BC 推断 |

因此正确更新方式是删除旧 12.21 的解答，再重编号旧 12.22–12.28；只删除旧 12.28 会让七道答案全部错位。

### Chapter 21：带宽约定写得更明确

- Exercise 21.5 的出版版用阈值 $59.1984\pm13.8$、$\pm7$、$\pm20$ 描述矩形窗口。它与矩形核带宽写法等价，但解答应明确区间筛选规则。
- Exercise 21.6 明确基准是**标准化三角核** $h=8$，并指出 Stata 等软件的未标准化三角核对应 $h=19.6$；敏感性组 $h=4,12$ 分别对应未标准化 $h=9.8,29.4$。代码和结果表必须标明采用哪一种归一化，不能只报“带宽 8”。
